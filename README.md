# insgpos-se3
IMU and GNSS fusion positioning based on SE2(3)

# Introduction
This project implements IMU and GNSS fusion positioning using the SE2(3)-based formulation. It is designed for robust and accurate state estimation in navigation and positioning applications by integrating inertial measurement data with global navigation satellite system (GNSS) observations.
